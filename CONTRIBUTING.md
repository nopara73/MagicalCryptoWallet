# Contributing

Open an issue or pull request in [nopara73/MagicalCryptoWallet](https://github.com/nopara73/MagicalCryptoWallet). Keep changes focused and describe the problem, behavior, and relevant validation.

Use the SDK in `global.json`, follow `.editorconfig`, and build native libraries from source. Run the wallet unit tests, vendored managed/native and interoperability tests, and `python Contrib/Branding/audit.py` before submitting a change. Configuration, wallet files, recovery material, and signing secrets never belong in a commit.

Product names, paths, generated code, and packaged applications are audited. Any retained upstream text requires an individually recorded copyright, provenance, immutable fixture, or negative-test exception. WabiSabi's protocol identifiers and wire format remain stable.
