# Security reporting

Report a vulnerability through [this repository's private reporting page](https://github.com/nopara73/MagicalCryptoWallet/security/advisories/new). Include the affected version, reproduction steps using synthetic wallets, and the expected impact. Do not post private keys, wallet files, recovery phrases, or sensitive transaction details in public issues.

For encrypted reports, use [PGP.txt](PGP.txt), fingerprint `552DC742598F1BE66485ADF3354986B46FAD0E7B`. General support belongs in [issues](https://github.com/nopara73/MagicalCryptoWallet/issues).

Update announcements must be authored by the project's Nostr key. Downloads must match the signed checksum manifest and the pinned update-signature key. Public trust material is in [Contrib/Signing/public-keys.json](Contrib/Signing/public-keys.json).
